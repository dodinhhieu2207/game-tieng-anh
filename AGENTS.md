# Project agent instructions

Read RULES.md before changing this learning app. For a new game or substantial game upgrade, also read docs/GAME_WORKFLOW.md and the relevant docs/game-plans/<game>/RULES.md and PLAN.md. Preserve approved artwork/audio, routes and progress. Update the game plan at meaningful checkpoints.

For every new game proposal, recommend suitable repos and skills, explain their roles and ask the user to choose the approach (or delegate the choice). Record the answer and do not re-ask for the same game. If a plan already records an approved stack, use it. Follow the current user's scope; do not implement unrelated games or rewrite the app framework.

## graphify
When the user types /graphify, read and follow the installed graphify skill before anything else. Do not trigger it solely because this project contains source files.
