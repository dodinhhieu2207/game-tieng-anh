# Family Dialogue Studio assets

- `room.png`: original generated, empty illustrated family living room. Six people are layered separately by the app; no textbook sticker boxes are included.
- `spotlight-arrow.svg`: original vector pointing cue created for this activity.
- `speaking-console.png` and `speaking-console-mobile.png`: original generated landscape and portrait speaking boards, with empty portrait/question/control areas for live content. Mint frame, honey trim, coral ribbon, quiet ivory interior.
- `answer-yes.svg`, `answer-no.svg`, `microphone.svg`, `listen.svg`, `word-tile.svg`, `sentence-slot.svg`: original scalable assets for this game's live controls and sentence assembly.
- The six stage characters reuse the approved full-body sheets in `assets/family-hide-seek/family-*.webp`; the focus cards use the approved sharp portraits in `assets/family-treehouse-talk/portraits/`.
- `audio/manifest.json`: eight newly generated Higgs V3 clips, exact question and answer transcripts checked with Whisper; `SOUND-CREDITS.md` lists the sampled SFX provenance.
