# Treehouse Talk portraits

Six transparent portraits were created with the built-in imagegen editor on 2026-11-03 from the corresponding supplied `assets/unit4/lesson1/matching/<word>.webp` crops. They are used only in Family Treehouse Talk; the approved textbook crops remain intact for other games.

Prompt set: preserve each named family member's face, hair, clothing and flat illustrated identity; clean scan/compression blur; make a high-resolution, front-facing bust with clear outlines, smooth fills, transparent margin, no text, no photorealism or 3D. Individual clothing and hair details were specified for mum, dad, brother, sister, grandpa and grandma.

The treehouse background and ornate oval frame were also edited from the existing `background.webp` and `portrait-frame.webp` using imagegen to improve edge clarity. Their originals remain beside the new assets as a fallback and provenance reference.
