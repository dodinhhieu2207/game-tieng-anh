# Kk and Ll letter asset kit

Own K, k, L, l artwork generated using OpenAI built-in image_gen, 2026-11-12, following the separate dimensional J/j sprites used in Magic Jug. Prompt: four isolated, clear preschool print glyphs on transparent alpha, K/k coral/honey/mint and L/l turquoise/honey/lavender, no faces/extra characters, lowercase l without crossbar or dot. Original source retained; exact generation ID and production hashes in manifest.

Kit: four separate glyph PNGs, four exact alpha-derived glow PNGs, Kk/Ll paired badges, four word-picture cards. Word toy images reuse approved Key Quest kangaroo, key, lion, lollipop to preserve known vocabulary. Card captions remain live App Outfit. Letter names and words reuse accepted Higgs clips; these do not stand in for isolated /k/ or /l/ phonemes.

Integrated in K/L houses, delivery stations, Workshop models and Key Quest key handles. The native E/F trace paths remain plain print outlines and ink, not decorative raster glyphs; gesture geometry is unchanged. Original H/I/J assets, routes, voices and progress preserved. `catalog.html` previews the whole kit and plays the actual Higgs files, without awarding progress.

Build: `tools/build_kl_letters.cjs` with generated source PNG path. Pair/card layout and blurred alpha VFX are deterministic asset processing, not replacement font approximations. No new raster is referenced from temporary/generated-images locations at runtime.
