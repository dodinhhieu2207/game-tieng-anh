# Dedicated Letter Pond UI artwork
Four independent built-in imagegen generations, not CSS-only decorative substitutes. Blank mission board, picture frame, blank word plaque and speaker button. Native alpha-bound crops and WebP export only. Exact prompts in prompts.json, original generation filenames/crop/size/SHA256 in manifest.json. Original generated images remain in Codex generation archive; runtime exports in this folder. No text is rasterized by AI: existing Outfit labels and approved vocabulary images render over these artwork layers. CSS nine-slice board/plaque preserves corner details across screen sizes. Existing accessible Listen button keeps its handler and aria label; generated speaker art is a child img with empty alt.
Export: tools/export_pond_ui.py (Pillow required only at build time). Inspect catalog.html. No existing scene/audio/progress asset replaced.
