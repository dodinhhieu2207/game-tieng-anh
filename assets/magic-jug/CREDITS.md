# Magic Jug sources
Garden, jug and glass: original built-in image_gen artwork for this activity. sources.json records source files, crop and hashes. Export is native alpha crop/resize, no painting or compositing.
Original SVG button, word plaque, icons: created for this game. Font: existing licensed App Outfit.
Pouring foley: “Running water” by Arthur, https://opengameart.org/content/running-water . Selected license CC BY-SA 3.0, https://creativecommons.org/licenses/by-sa/3.0/ . Recording made pouring between glasses. Original archived as sources/running-water.wav. pour.ogg is a normalized excerpt with short edge fades, same CC BY-SA 3.0. License applies to this audio adaptation, no bundled source-code copying.
PixiUI and Pixi Creation Templates: UI design references only, no copied implementation or additional runtime. Local PixiJS/GSAP retain their existing licenses.
Higgs V3 new finite catalogue: audio/manifest.json. Letter clip is letter name J, not isolated phoneme /dʒ/.
