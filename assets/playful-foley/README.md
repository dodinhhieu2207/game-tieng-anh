# Sampled classroom SFX

Creator: Kenney. Packs: [RPG Audio](https://kenney.nl/assets/rpg-audio), [Impact Sounds](https://kenney.nl/assets/impact-sounds). Both CC0; source license files retained. Downloaded through publisher's public download-link flow on2026-10-29. Selected original OGG files retained alongside production WAVs. Manifest records source per cue and export hash.

Real sampled wood/book/cloth/glass/coin/metal sounds; no generated oscillators. Detect first transient at10% source peak and retain20ms lead; trim before normalization to avoid cutting off the page-turn onset. Selected cues are deliberately bounded, high-passed at100Hz and normalized to-24LUFS/-6dBTP before a25ms ending fade. Playback gain is further reduced; UI clicks duck under speech. This is technical leveling, not a listener approval claim. Preview.mp3 plays tap/place/retry/correct/complete/open/reveal/star at source level with220ms silence between them; app gain is lower.

Roles: tap=light wood contact; place=book placed; retry=cloth movement; correct/complete=light glass; open=book opening; reveal=page turn; star=coins handled; roll=cloth motion; latch=metal latch. Source-pack labels describe provenance, not new vocabulary taught to children.

Runtime: local Howler core2.2.4. One bounded SFX lane; repeated identical triggers throttled, speech cancels decorative SFX, very brief UI cues may survive navigation quietly, recording/mute/hidden stop all. No old queued feedback follows a route change. Failed sample can reload on retry. Approved Higgs speech stays on its original audio path.
