# Sound Garden assets

Generated with built-in imagegen on 2026-10-14. Transparent nine-cell atlas extracted into independent WebP sprites; alpha and original art retained. Individual files: petal, center, stem, bee body, wing, soil, seed, sprout, button. The original generated atlas remains in the generation folder; the consuming game uses only the saved workspace sprites.

Prompt: polished matte storybook preschool sprite sheet, precise 3×3 cells, isolated pink upright petal; golden smiling flower center; green stem/two leaves; right-facing bee body without wings; detached pale-blue wing; soil mound; golden seed; two-leaf sprout; blank teal cloud button. Transparent background, no labels, no overlapping cells, soft warm light, avoid glossy plastic.

Vocabulary art and audio reuse Letter Land A–D/G. Scene background reuses the approved Unit 3 Lesson 3 sorting-garden.webp. No new vocabulary image or voice substituted. SFX use the shared LearningFeedback library (Kenney CC0 sources/license in assets/feedback/manifest.json).

PixiJS owns scene/sprites; GSAP animates points, rotations, scales and paths. Button labels and picture hit targets remain accessible DOM elements.
