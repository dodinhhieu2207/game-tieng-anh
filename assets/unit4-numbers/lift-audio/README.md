Family Number Lift uses Kenney Sci-fi Sounds, CC0: https://kenney.nl/assets/sci-fi-sounds . Original samples and publisher license are retained in this directory.

Departure uses a short door-close mechanism as a lock/start cue (the visible doors start closed). Opening uses doorOpen_000 slowed to align with the sliding doors. Moving uses a low-volume filtered engineCircular_000 bed. These are designed mechanical game effects, not field recordings of an elevator.

Native SFX playback follows actual moving/opening states. It pauses with motion and stops before Higgs, on mute/SFX off, on leaving, and on restart. No synthesized speech or oscillators. Reproducible exports: tools/build_lift_sfx.py; processing and hashes: manifest.json.
