# Family Links portrait assets

Source: supplied Family and Friends Starter 2nd Class Book, Unit 4 Lesson 1, page 32. Six portrait crops derived from existing `family-portraits.webp` with FFmpeg: width 180, height 166, y=54, x=0/190/380/570/760/950; export 360x332 WebP. Printed word labels are excluded.

Order in source: mum, dad, brother, sister, grandpa, grandma. These are source-book portraits, not generated replacement characters. New activity uses existing navigation-v2 background and local Higgs word clips. PixiJS 8.22.0 renders connections and endpoint particles; GSAP animates growth/retraction.
