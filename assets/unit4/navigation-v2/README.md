# Unit 4 matching navigation and lesson backgrounds

Created 2026-10-27 with the built-in image-generation tool, using actual Unit 3 assets as visual references. Full final prompts and generation source paths are stored in `manifest.json`.

- `unit-card.webp`: Unit 4 / Family Park / 6 lessons badge.
- `lesson1-card.webp` through `lesson6-card.webp`: complete rounded banners with Unit/Lesson tags, large title, subtitle and topic illustrations.
- `lesson1-background.webp` through `lesson6-background.webp`: full lesson-library backgrounds with clear central space.

Lesson mapping: Family; This is my mum; Jj jug/juice; Numbers 9/10; Kk kangaroo/key and Ll lion/lollipop; My brother story.

The shared design direction follows Unit 2/3: rounded glossy rim, bold navy-outlined lettering, saturated cartoon art, clouds and stars. New images replace the earlier navigation-only painterly set in app configuration. Gameplay textbook artwork, audio and progress remain owned by the existing activities.
