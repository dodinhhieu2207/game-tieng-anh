# Roles and Mystery Toy

What's this? — Ask displays the student icon, highlighted YOU ASK → TOY BUDDY ANSWERS, and the buddy's “Ask me!” bubble. What's this? — Answer displays YOU ANSWER ← TOY BUDDY ASKS. Ask mode plays the existing Higgs “Your turn!” cue rather than having the buddy ask the child's question. A correct student question receives the existing Higgs “It's a <toy>.” response.

The additional Mystery Toy — Ask & Guess mode uses five shuffled secret toys. It displays the original question-mark art instead of the toy image or toy alt text. Cloudflare transcribes the child's full “Is it a <toy>?” question. `mystery-question` evaluation returns CORRECT for a grammatical supported question plus `guessedToy`; CORRECT here does not mean the secret has been found. The scene compares that toy with its current secret and plays existing Higgs Yes/No audio. No leaves the secret hidden and enables another question. Yes reveals the toy after answer audio ends, celebrates and enables Next. No automatic round completion occurs on a negative answer.

Each full recognized question (including a repeated question) counts once. Incomplete or unclear speech does not count. Replay, teacher fallback and support changes retain the round's count. Changing Speaking starts a new set. Scores: one question = 3 stars; 2–3 = 2 stars; 4+ = 1 star. Five rounds offer up to 15 mystery stars; the final activity badge is the rounded mean of the round stars. This is classroom game scoring, not a server-verified leaderboard. Teacher fallback selects the toy actually asked in the child's full question instead of a blind CORRECT button.

No new TTS, audio storage or general LLM is added. The existing transient Cloudflare transcription endpoint remains in use. Contract tests cover all 25 secret/guessed toy pairs. Browser tests exercise real MediaRecorder bytes through the Worker handler with mocked inference, partial/noise, negative retries, repeated guesses, reveal and audio gating, 1–5 guess scoring, completion, replay/support continuity, teacher fallback and 1366/1024/390/320px layouts. Live tests check all five Higgs question recordings through deployed Cloudflare Whisper. Those adult voice clips do not measure classroom child voice accuracy.
