# Toy Buddy: toy names and question practice

Game 6 adds a Speaking selector alongside Support. The original yes/no activity stays the default (10 balanced rounds). “What's this? — Answer” has five rounds, one for each original toy. Children must say “It's a plane/puppet/robot/balloon/teddy.” “What's this? — Ask” has five rounds in which children ask the whole question; after a correct question, the buddy answers with the displayed toy's name sentence. All modes preserve microphone audio-ended gating, Teacher Check, replay, character and feedback.

Easy displays the sentence structure, Practice displays an instruction, and Challenge asks for the whole sentence without displaying its structure. Naming support does not reveal the toy's answer. Changing Speaking starts a fresh set of rounds and cancels previous audio. Switching is disabled during question playback, recording and checking.

The multipart API adds `questionType`: `yes-no` (default for older clients), `name`, or `name-question`. Worker validates this field. The shared deterministic evaluator requires “it's a <toy>” or “it is a <toy>”. Missing sentence structure or article is INCOMPLETE; a full sentence with the wrong toy is WRONG_LOGIC. It accepts equivalent punctuation/apostrophe forms without fuzzy word corrections. Question practice accepts “what's this” or “what is this”. Unrelated speech stays UNCLEAR. The transcription prompt remains neutral vocabulary context. Recordings are transient; no new persistence or secrets.

The existing Higgs `questions/whats_this` recording is reused. Five existing approved Belinda `assets/unit3/audio/its_a_*.mp3` recordings are referenced unchanged, with waveform/transcript mouth cues added to the Lesson 2 manifest by `tools/reuse_toy_name_audio.py`. No new TTS voice or browser synthesis is introduced. `build_unit3_lesson2_audio.py` reapplies these references after a build.

Validation: Worker contract test covers 330 grammar/meaning cases across all toys and question types, including invalid question types. Browser speech test includes 28 real MediaRecorder uploads through the Worker handler with inference mocked, including all five toys in both added modes. Live Cloudflare test uses existing adult Higgs clips: all five full naming sentences, a bare toy, a wrong-toy full sentence and the full question. These are integration checks, not evidence of accuracy for children's voices. Voice presentation checks cover the added selectors/support copy at desktop and 390/320px widths. Existing lesson games and preserved engines retain their regression checks.
