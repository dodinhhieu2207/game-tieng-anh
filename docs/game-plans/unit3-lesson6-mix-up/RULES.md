# Lesson 6 companion game rules
User authorized continuing the previously proposed Your Turn and Story Mix-Up games. Reuse the Lesson 6 approved Phaser + GSAP stack, existing shell/font/progress and source art/audio. No new framework/provider. Preserve Story Studio route and all previous lessons. Child UI English, 48px targets, five widths, reduced motion, mute/pause/hidden/leave and explicit retry. No false ASR/pronunciation/child-accuracy claims.
Shuffle four approved story images; tap-select or pointer-drag into numbered slots. Tap filled slot to return image. Check order only when all slots filled. Wrong order keeps children in control and highlights positions to rethink without giving a fake success. Correct order earns shared practice progress, reveals Listen to your story; replay original scene audio in sequence with actual media-ended transitions. No automatic full-story replay on wrong or incomplete arrangement.
